# แผนระบบตรวจสลิปอัตโนมัติ — Automatic Payment-Slip Verification Plan

> **Executive summary (EN):** Today payment confirmation is manual (admin clicks ยืนยัน). Two viable routes: **A) a real payment gateway** (Opn/Omise PromptPay, 1.65% + VAT — no slip at all, webhook auto-confirms) or **B) a slip-verification API** (SlipOK, ~฿0.35–1.00/slip on small tiers — customer uploads slip, API validates against the bank, order auto-confirms). Recommendation: **B (SlipOK START, ฿350/เดือน)** — money keeps landing directly in the store's PromptPay account, no gateway KYC/payout delay, and it kills fake slips. Gateway can be added later for card payments.

---

## 1. สถานะปัจจุบัน

- ลูกค้าสั่งซื้อ → สร้างออเดอร์ `pending_payment` → ขึ้น **QR PromptPay** (ตอนนี้เป็น mock ใน dev — ระบบจริงคือบัญชีพร้อมเพย์ของร้าน)
- ลูกค้าโอนเงินเองผ่านแอปธนาคาร → แอดมิน**เช็คสลิปเองในหน้าคำสั่งซื้อแล้วกด ยืนยันการชำระเงิน** → ออเดอร์เข้าสู่ `payment_confirmed` → ระบบส่งโค้ดอัตโนมัติ
- ปัญหา: แอดมินต้องตามเช็คเอง, มีความเสี่ยงสลิปปลอม/สลิปซ้ำ, ลูกค้ารอ

โค้ดรองรับอยู่แล้ว: state machine ของออเดอร์ครบ, `OmiseAdapter` มี scaffold ไว้ (ยังเป็น mock), ระบบส่งโค้ดหลังชำระเงินทำงานแล้ว

## 2. ทางเลือก

### A) Payment Gateway จริง — Opn Payments (Omise) PromptPay
**หลักการ:** ลูกค้าสแกน QR ที่ระบบสร้างจาก Opn → เงินเข้าผ่าน Opn → webhook แจ้งเว็บอัตโนมัติ → ออเดอร์ยืนยันเอง **ไม่ต้องมีสลิปเลย**
- **ค่าธรรมเนียม: PromptPay 1.65% / รายการ (+VAT = ~1.77%)** (บัตรเครดิต 3.65%)
- ✅ อัตโนมัติ 100%, ตัดปัญหาสลิปปลอมโดยสิ้นเชิง, รองรับบัตร/TrueMoney เพิ่มภายหลัง
- ❌ ต้องเปิดบัญชี merchant + KYC (เอกสารธุรกิจ/บุคคล, อนุมัติ ~1-2 สัปดาห์), เงินเข้าบัญชีแบบ payout (ถึงเวลา T+1/T+2 ไม่ทันที), เงินไม่เข้าพร้อมเพย์ร้านตรง

### B) Slip Verification API — SlipOK (ทางแนะนำ)
**หลักการ:** ลูกค้าโอนเข้าพร้อมเพย์ร้านตามปกติ → อัปโหลดรูปสลิป (หรือแชร์ payload จากแอป) → API ตรวจกับธนาคารจริง: **ยอดตรง, บัญชีรับตรง, เลขอ้างอิงไม่เคยใช้** → ออเดอร์ยืนยันเองใน ~1-3 วินาที
- **ค่าบริการ (2026):** OK BASIC ฟรี 100 สลิป/เดือน (ทดลอง) · OK START **฿350/เดือน 500 สลิป** · OK SME ฿600/1,000 · OK ENTERPRISE ฿1,000/2,000 · OK GOLD ฿2,580/9,000 · ราคาอาจปรับ ตรวจอีกครั้งก่อนสมัคร
- ✅ เงินเข้าบัญชีร้าน**ทันที** (ไม่มี KYC/payout), จับสลิปปลอม/ซ้ำได้, แอดมินยังกดยืนยันเองเป็น fallback เมื่อ API ล่ม
- ❌ ลูกค้ายังต้องอัปโหลดสลิป 1 ขั้น, มีค่า service รายเดือน

### C) คงแบบ manual (ฟรี)
ปัจจุบัน — 0 บาท แต่แอดมินต้องตามเช็คเองและเสี่ยงสลิปปลอม

## 3. เปรียบเทียบค่าใช้จ่าย (สมมติยอดเฉลี่ย ~฿50/ออเดอร์)

| ออเดอร์/เดือน | A: Opn (1.77%) | B: SlipOK | C: Manual |
|---|---|---|---|
| 100 (ช่วงเริ่มต้น) | ~฿89 | **฿0** (BASIC) | ฿0 |
| 500 | ~฿445 | **฿350** | ฿0 |
| 1,000 | ~฿890 | **฿600** | ฿0 |
| 2,000 | ~฿1,780 | **฿1,000** | ฿0 |

- ยิ่งยอดต่อออเดอร์สูง ยิ่ง B คุ้มกว่า A (B เหมาจ่ายรายสลิป, A คิดเปอร์เซ็นต์)
- ต้นทุน B ต่อออเดอร์ ~฿0.35–1.00; A ~฿0.44 ที่ยอด ฿25 แต่ ~฿2.65 ที่ยอด ฿150

## 4. งานที่ต้องทำ (ประเมินจากโค้ดจริงของเว็บนี้)

| รายการ | A: Gateway | B: SlipOK |
|---|---|---|
| Backend | เขียน Omise API จริงใน adapter ที่มี + webhook route (verify signature, idempotent) ผูกเข้า `payment_confirmed` → ส่งโค้ด | route `/api/v1/payments/slip-verify`: รับรูป/payload → เรียก SlipOK → เช็คยอด+บัญชีรับ+ref ซ้ำ → ยืนยันออเดอร์ |
| Frontend | QR จาก Opn แทน mock, polling สถานะ | หน้าอัปโหลดสลิปหลังจ่าย + สถานะตรวจแล้ว |
| Admin | ป้าย "ยืนยันอัตโนมัติ" (ปุ่มยืนยันคงไว้เผื่อฉุกเฉิน) | เหมือนกัน + แสดงผลตรวจ (ยอด/เวลา/ref) |
| เวลาทำ | **~2–3 วัน** | **~1.5–2 วัน** |
| เอกสาร/สมัคร | KYC Opn (1–2 สัปดาห์) | สมัคร SlipOK + top-up เครดิต (วันเดียว) |
| เวลาเงินเข้าร้าน | T+1/T+2 (ผ่าน Opn) | ทันที (เข้าพร้อมเพย์ร้านตรง) |

## 5. ข้อเสนอแนะ

**เริ่มด้วย B (SlipOK):** ตรงกับโจทย์ "ตรวจสลิปอัตโนมัติ" เป๊ะ, เงินเข้าร้านทันที, ไม่ต้องรอ KYC, มีฟรี 100 สลิป/เดือนให้ทดลองก่อนตัดสินใจ, และปุ่มยืนยันแอดมินยังอยู่ครบเป็น fallback — เสี่ยงต่ำสุด อัปเกรดไป A (gateway) ภายหลังได้เสมอถ้าอยากรับบัตรเครดิต/ให้ลูกค้าจ่ายไม่ต้องอัปสลิป

**ประเด็นให้ลูกค้าตัดสินใจ:**
1. เลือก A หรือ B (หรือทั้งคู่ในอนาคต)
2. ถ้า B: เริ่ม BASIC ฟรี ก่อน หรือจ่าย START ฿350/เดือนเลย
3. เงื่อนไขยืนยันอัตโนมัติ: ยอดต้องตรงเป๊ะ (ไม่รับโอนขาด), บัญชีรับต้องตรง, 1 สลิปใช้ได้ 1 ออเดอร์
