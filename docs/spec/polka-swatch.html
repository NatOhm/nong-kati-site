What was rejected

  • peach-300 @ 22% — the earlier placeholder: 1.10:1 on cream, which reads as printer grain, not polka. The gap between “too faint to see” and “dirty” is about 10 points of alpha, so the value has to be measured.
  • A dot image or SVG asset — nothing to cache-bust, nothing to load, zero height.
  • Any hue outside the clay/peach ramps, and any background-color on .polka itself: it would override the promo band's coral underlay and the contrast scanner follows the background-color chain.

If the logo file arrives later

  • Only --texture-dot changes (both themes), plus --texture-dot-size / --texture-dot-gap if the logo's pitch differs. Re-derive the alpha so the composite stays in the 1.14–1.20 band on that theme's base.
  • .polka, .polka-sm, .polka-lg, PolkaBackdrop, MascotHalo and every call site stay untouched — one commit, tokens.css + design-system.md together.
  • Irregular or non-circular dots: either accept the radial-gradient approximation or add the single polka-mask.svg the spec already allows.
  • No screenshot, gate or first-viewport number changes: the texture adds zero height.
