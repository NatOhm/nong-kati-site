# Client Acceptance Checklist — ครบทุกข้อในลิสต์ล่าสุด

ทุกข้อจากลิสต์ล่าสุดของลูกค้า เรียงตามหมวดเดิม พร้อมสถานะจริงจากโค้ดและเว็บ
(https://nong-kati.vercel.app) — ✅ ใช้ได้แล้ว · 🟡 มีส่วนใหญ่ (ขาดเล็กน้อย) · ⬜ ยังไม่ทำ
ตัวย่อ: MP = `/management` (แผงแอดมิน) · ทดสอบด้วยบัญชีจาก `docs/customer-login-test.md`

> **ตรวจซ้ำครั้งล่าสุด: 23 ก.ย. 2569** — กดเช็กทุกข้อกับหน้าเว็บ/API จริงอีกรอบ
> (หน้าแอดมินทั้ง 16 หน้า 200 · หน้าแรก/ค้นหา/หมวด/สินค้า/โปรไฟล์ทำงานครบ)
>
> **อัปเดต 26 ก.ย. 2569** — ทบทวน 2 ข้อที่เคยค้าง (A9, A16) กับโค้ดจริงหลัง
> สัปดาห์งานหนัก (login 4 ช่องทาง · แก้ security review · แก้ UX audit ·
> design system v2.1) — รายละเอียดในตารางและสรุปท้ายเอกสาร

## สรุป (อัปเดต 26 ก.ย. 2569)

- **✅ 36 ข้อ** · **🟡 1 ข้อ** (ตรวจสลิปอัตโนมัติ — โค้ดพร้อม รอใส่ `NK_SLIP_OK_KEY` ใน Vercel เท่านั้น) · **⬜ 0 ข้อ**
- ยกเป็น ✅ 3 ข้อสะสม: **ยอดซื้อรายคน (A12)**, **สินค้าค้างสต๊อก (A15)** และ **เปลี่ยนรูปมาสคอต (A16 — อัปได้จากหน้าแอดมินแล้ว)**
- **เพิ่มใหม่สัปดาห์นี้ (26 ก.ย., ไม่ได้อยู่ในลิสต์เดิม):**
  - ล็อกอินลูกค้าครบ 4 ช่องทาง: Google / LINE / Facebook / เบอร์โทร (SMS OTP) — ปุ่มแสดงเมื่อใส่คีย์; โทรศัพท์ทำงานแล้วใน dev รอคีย์ Twilio
  - **ชำระเงินด้วยการโอน + อัปโหลดสลิปในหน้าเช็กเอาต์** แอดมินตั้งเลขบัญชีเองได้ (MP → ตั้งค่า → การชำระเงิน → "โอนเงินแมนนวล") ⚠️ **ยังไม่เปิดใช้ — เปิดเลยนะ ไม่งั้นลูกค้าจ่ายไม่ได้**
  - แก้ security review ครบ (secret fail-closed, ยืนยันการชำระแบบ atomic, กันยืนยันออเดอร์คนอื่น, กันสแปม magic link)
  - แก้ UX audit ครบ 9 ข้อ (ลิงก์กฎหมาย 404, คำโฆษณาบัตรที่ยังไม่มี, ตัวเลขปลอม, drawer/a11y ฟอร์ม, "ลืมรหัสผ่าน?")
  - ดีไซน์ v2.1: เงา 3 ระดับ, เช็กเอาต์แบนลง, แฮมสเตอร์มีบทบาทตามสถานการณ์ (ฉลองเมื่อจ่ายสำเร็จ)
- ⬜ ตรวจสลิป: ฝั่งระบบ implement ตามแผน **SlipOK** ใน `docs/payment-verification-plan.md` แล้วครบ — เหลือสมัครบัญชี + ใส่ `NK_SLIP_OK_KEY` (ถ้าจะเปลี่ยนไปใช้ PromptPay gateway แท้ ต้องแก้โค้ดเพิ่ม)
