# สรุปงานประจำสัปดาห์ — Nong-Kati (สัปดาห์สิ้นสุด 20 ก.ย. 2569)

เว็บจริง: **https://nong-kati.vercel.app** · ทุกงานในลิสต์นี้ทดสอบบนเว็บจริงแล้ว ไม่ใช่แค่เขียนโค้ดทิ้งไว้

---

## ภาพรวมสัปดาห์นี้

ปิดงานไป **20+ รายการ** — โฟกัสหลักคือ ระบบราคาสมาชิก/ตัวแทน ครบวงจร, หน้า /search และ หน้าสินค้า ใหม่ตาม mockup ที่ลูกค้าส่งมา, และเครื่องมือแอดมินสำหรับงานขาย (แท็ก, นำเข้า CSV, ราคาทีเดียวทั้งเว็บ)

**สถานะตามลิสต์ฟีดแบ็กของลูกค้า: เสร็จแล้ว 24 จาก 27 ข้อ** — เหลือของจริง 3 ข้อ (ดูหัวข้อ "ยังเปิดอยู่" ด้านล่าง)

## เสร็จแล้วสัปดาห์นี้

### 💰 ระบบราคาสมาชิก/ตัวแทนจำหน่าย (ครบวงจร — ข้อ 5 ในลิสต์)
- ทุกสินค้าตั้ง **ราคาปลีก / ราคาสมาชิก / ราคาตัวแทน** แยกกันได้
- ลูกค้าแต่ละระดับเห็นราคาของตัวเองทันที — หน้าแรก, หน้าค้นหา, หน้าสินค้า, ตะกร้า, ชำระเงิน
- ออเดอร์บันทึกราคาตามระดับจริงฝั่งเซิร์ฟเวอร์ (ลูกค้าแก้ราคาเองไม่ได้)
- แอดมินเปลี่ยนระดับลูกค้าได้ในหน้า ลูกค้า
- **ใหม่ล่าสุด:** ปุ่ม **ราคาสมาชิก/ตัวแทนทีเดียว** — ใส่ % ของราคาปลีกแล้วคิดเงินให้ทุกสินค้าพร้อมกัน พร้อมตารางพรีวิวก่อนบันทึก และโหมด "เติมเฉพาะช่องที่ยังว่าง" ที่ไม่ทับราคาที่ตั้งมือเอาไว้
- **บั๊กเก่าที่จับได้จากการทดสอบ:** หน้าสรุปการชำระเงินเคยบวก VAT 7% ทับราคาที่รวม VAT อยู่แล้ว (แสดง ฿107 แต่ตัดจริง ฿100) — แก้แล้ว ตอนนี้ตัวเลขตรงกันทุกจุด

### 🛒 หน้าร้านตาม mockup
- **หน้า /search ใหม่:** การ์ดแบบรูปเต็มบล็อก + หัวใจถูกใจ + ปุ่มซื้อเส้นขอบ, แถบเครื่องมือ (ค้นหา / เรียงตาม / เลื่อนหน้า 1/2) — ซื้อจากการ์ดได้เลย, สินค้าหลายแพ็กเกจเด้งหน้าเลือกราคา
- **หน้าสินค้าใหม่:** แบนเนอร์กว้างชื่อสินค้าทับบนรูป + หัวใจบนแบนเนอร์, ขั้นตอนเลข ① เลือกแพ็กเกจ (การ์ดกระดาน ไฮไลต์แอปพีช) ② จำนวน + ปุ่มใส่ตะกร้า — ตรงตามภาพที่ลูกค้าส่ง
- การ์ดโค้ดตัวอย่าง "รหัสสินค้าของคุณถูกส่งแล้ว" — **ลูกค้าตัดสินใจแล้ว เอาออกถาวร** ✅ ลบสะอาดแล้ว

### 🏷️ เครื่องมือแอดมิน (ปิดข้อ 2 และ 8 ในลิสต์)
- **แท็กสินค้า:** หน้า แท็ก ในเมนูข้าง (สร้าง/เปลี่ยนชื่อ/ลบ + นับสินค้าอัตโนมัติ), เลือกแท็กในหน้าแก้ไขสินค้า, หน้าร้านแสดง #แท็ก — เช่น ขายดี, มาใหม่, ส่งฟรี
- **คูปองส่วนลด:** ลิงก์ในเมนูข้างแล้ว (เดิมต้องพิมพ์ URL เอง)
- **นำเข้า CSV:** วางตารางหรืออัปโหลดไฟล์ เพิ่ม/อัปเดตสินค้าเป็นก้อนตาม SKU

### 🐹 ธีมหนูแฮมสเตอร์
- การ์ดทุกใบยกตัวตอนชี้เมาส์ (มีทั้งโหมดสว่าง/มืด), แถบข่าววิ่งหมุนได้, เพจเฟดอิน-เอาต์, ปุ่ม/เมนูสไลด์ 550ms, ตัวการ์ตูนหนูบนหน้าแรก + หนูในหญ้า (มีอีสเตอร์เอ็กก์กดแล้วเด้งขึ้นโรยเมล็ด)
- **รองรับมือถือจริง:** แก้ปัญหาแบนเนอร์คุกกี้บังแถบเมนูล่าง, ปุ่มกดแตะเล็กเกิน, จอ iOS ซูมเองตอนพิมพ์ค้นหา

### 🔒 ความปลอดภัยและความเสถียร
- ระบบล็อกอินแอดมินใช้ฐานข้อมูลจริง + รหัสผ่านเข้ารหัส + 2FA (แอป Google Authenticator) + เปลี่ยนรหัสผ่านเองได้ + จำกัดจำนวนความพยายาม
- เซสชันแอดมินต่ออายุอัตโนมัติ ไม่ต้องล็อกอินใหม่ทุก 15 นาที
- จำกัดอัตรายิง API (กันสแปม), หน้า checkout ไม่ให้ Google จับตัว, ตรวจสอบสิทธิ์ทุก endpoint ของแอดมิน
- อัปเกรด Next.js + แก้ช่องโหว่ที่สแกนเจอครบ ทั้งหมดผ่านการทดสอบ 28 ข้อบนเว็บจริง

## ยังเปิดอยู่ — ต้องการอะไรจากลูกค้าบ้าง

| รายการ | สถานะ | ต้องการจากลูกค้า |
|---|---|---|
| **ตรวจสลิปอัตโนมัติ** | ⬜ ยังไม่ทำ (ข้อเดียวในลิสต์ที่เหลือจริง) | **การตัดสินใจ** — เตรียมแผน + เปรียบเทียบราคาไว้แล้ว (SlipOK เริ่มฟรี 100 สลิป/เดือน หรือใช้ gateway PromptPay คิด 1.65% ต่อรายการ) ตอนนี้แอดมินกดยืนยันสลิปเองก่อน ซึ่งใช้งานได้ปกติ |
| **สรุปยอดขายรายตัวแทนแยกหน้า** | 🟡 เกือบเสร็จ | ยืนยันหน้าตาที่ต้องการ — ตอนนี้ดูยอดรวมในแดชบอร์ดได้ แต่ยังไม่มีหน้าแยกรายคน |
| **เปลี่ยนรูปมาสคอต/ไอคอนหนูในแอดมิน** | 🟡 เกือบเสร็จ | ส่งรูปที่ต้องการมาได้เลย — ตอนนี้เปลี่ยนสีธีม + ความเร็วแอนิเมชันในหน้า ตั้งค่า ได้แล้ว ส่วนรูปมาสคอตยังต้องแก้โค้ด |
| **% ราคาสมาชิก/ตัวแทนที่จะใช้จริง** | ตั้งค่ารออยู่ | บอกตัวเลขมา (เช่น สมาชิก 80%, ตัวแทน 70%) แล้วกดใช้ได้เลยในหน้าสินค้า |
